# متجر القرطاسية — متليلي الشعانبة

## خطوات التشغيل (من الصفر)

```
1. افتح المجلد في VS Code
2. اضغط Ctrl+` لفتح Terminal
3. شغّل الأوامر التالية:
```

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python setup.py
python manage.py runserver
```

- المتجر:        http://127.0.0.1:8000
- لوحة الإدارة:  http://127.0.0.1:8000/dashboard/
